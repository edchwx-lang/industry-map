# Style specification

共同版式：默认 3840×2160、16:9、白底；主标题按整张画布水平居中且标题组件 padding 为 0，顶部 80 px，4K 基准字号 64 px，采用思源宋体/宋体风格；地图顶部从 250 px 开始，与标题保留明显留白。地图主体在左侧，右侧保留约 16% 空间放低到高竖排图例。图例标题在 4K 下使用 32 px 基准字号和常规字重。默认画面只含主标题、地图主体和右侧图例。副标题、来源、注释仅在用户明确提供时出现。不得加载在线瓦片、字体、脚本或数据。

地图先采用明确投影，再使用 contain 等比例缩放；禁止横向或纵向独立拉伸。图例置于右下独立区域，不靠压缩地图容纳图例。

全球两种模式都隐藏实际最低档国家名称及未匹配国家名称，只标注较高档位；5档时即较高4档，不能硬编码100为阈值。全国和地方仍标注全部行政区。隐藏名称不改变几何、数据、着色、分级或审计。

标签采用不透明深灰 #161B22、700字重、透明背景，无描边和阴影。4K基准字号28px，实际显示51个及以上标签时使用24px并记录密度警告。导出检查标签矩形，重叠标签就近移动并加引导线；不得再因拥挤删名，无法排开时阻断导出。深红、深蓝底色上需检查原尺寸可读性；必要时优先调整标签位置或使用引导线，不恢复白底或重影。`labels.showValues: true`只增加可见标签的数值，不改变可见范围。

## Classification and palettes

- 门禁推荐 5 级自动分级；用户也可明确选择 3–7 级自动分级或自定义阈值。渲染器不静默采用推荐值。
- 非负指标的图例首档从 0 开始展示；末档只写“下限及以上”，不显示有限上界。该规则只改变图例文案，不改变按源数据计算的分类与着色。
- 自动分级支持 `auto`、`equal`、`quantile`、`jenks`；`classification.source` 为 `user-confirmed`。`auto` 只选择方法，不改变级数。
- 自定义分级使用各档下限 `thresholds`，`classification.source` 为 `user-defined`。阈值必须有限、严格递增且数量等于 `classes`；非负数据从 0 开始。全部区间采用左闭右开，最后一档为“末阈值及以上”，例如 `[0,5)` 显示 `0–<5`，末档显示 `35及以上`。
- 同一批数据绘制两种图时，两图默认采用相同颜色、级数与分级方案，用户明确要求时才分别设置。
- `blue-a`：`#EFF4FC #D9E5F7 #B5CCED #88ACE0 #5685C5`。
- `orange-a`：`#FFF3E6 #FFD8AE #F6B66C #E68532 #B94B1C`。
- `mixed-c`（红蓝白，B版重排）：`#F7F7F7 #92C5DE #0571B0 #F4A582 #CA0020`。从低到高：近白、浅蓝、蓝、浅红、红；最小数量为白色，最高数量为红色。“红蓝白”名称按高到低描述，颜色数组按低到高排列。气泡和图例保留深色细边。旧 mixed-c 编号仅用于兼容。
- `blue-a`、`orange-a`、`mixed-c` 均可与分级颜色图或分级气泡图自由组合。
- 非 5 级时由五个锚点确定性插值，保留首尾颜色。

## Choropleth

- 每级使用固定颜色；null/unmatched 为中性灰，数值 0 仍作为有效数据。
- 同时含负值和正值且为默认 5 级时，使用以 0 为中心的对称发散分级。
- 右下使用带边框色块的矩形图例，并显示“指标名（单位）”与互不重叠的分级区间。

## Bubble

- 最低档不绘制气泡（包括非零值）；保留灰色底图，全国和地方仍保留名称，全球隐藏最低档名称。图例首档为灰色矩形；其余档位沿用原颜色和直径，不重新编号。所有档位仍计入分类统计与审计。

- 同一指标同时用颜色深浅和气泡大小编码。先分级，再给每级固定颜色和固定直径。
- 4K 基准下最小/最大直径为 32/144，级间按圆面积等差；0 使用最低等级，负值阻断。
- 浅中性 polygon 底图；圆心采用面内稳定点，不能落入 hole；`MultiPolygon` 使用最大有效面。
- 右下图例使用颜色与半径同步递增的分级圆图例，并显示“指标名（单位）”与互不重叠的分级区间。所有数值均进入审计。

## Visual review

实际打开 PNG，核对：标题居中、两种图版式一致、右侧图例完整、几何未变形、标签可读、气泡尺寸和颜色均按级别固定、圆心没有越界。再检查 SVG 含矢量 path、PDF 单页比例正确。不得用生成式图像修补边界。
