# Third-party notices / 第三方说明

The runtime bundles third-party JavaScript libraries. Their license and notice files are retained under [third-party-licenses](third-party-licenses/), organized by dependency name. These licenses apply to the respective upstream software, not automatically to this project's original code or geographic data.

运行时包含第三方 JavaScript 库，其许可与声明按依赖名称保存在 `third-party-licenses/`。相关许可仅适用于对应上游软件，并不自动授权本项目原创代码或地理数据。

Geographic data sources, hashes, and usage restrictions remain in [boundary/manifest.json](boundary/manifest.json). No new blanket license is assigned to those assets by this release.
